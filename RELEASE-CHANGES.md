# Changes from the studies' files

This release copies the four studies' files (D3 with its third round, D4, D5, X1), four helper modules of the companion line-breaking study
(D1), the paper's source and number scripts, and the three single-study papers' sources and number scripts. Files are
byte for byte the originals, except those listed below with the original's SHA-256 and the release copy's SHA-256:

- **Shell scripts:** the local interpreter path became `${PYTHON:-python3}`, the lock files' folder `$HOME/.cache/`,
  and one `cd` into the study folder `cd "$(dirname "$0")"`.
- **Records** (charters, protocols, freeze records, amendments, reports, D4's notebook, check reports): local paths
  became placeholders such as `<area>` and `<workbench>`, tool names `[redacted]`, and personal wording neutral
  wording (the categories are listed with each file).
- **The paper's number scripts** (`paper/scripts/`): the folder holding the studies is the release root.
- **D3's paper check** (`D3-indentation/paper/v2-2026-11-09/scripts/check_numbers.py`): its three comparisons of
  frozen files with `FROZEN.md` go through `tools/frozen_digest.py`, which returns the frozen original's SHA-256 for a
  file changed for the release only if this record lists exactly that change, and for the unshipped sealed reserve
  only if this record lists it with the frozen SHA-256.
- **D5's paper number scripts:** the two counts of the unread heading reserve come from `SEALED-MATERIAL.json`.
- **Two other authors' papers** that D3's reference check searches are replaced by the short passages it searches.
- **Chunk counts of the third-party parts that are not shipped** (D3's paper number build and check, D3's round-2
  checker `code/r2_independent.py`): read from the chunk digest lists `part-*.chunks.jsonl`, which give the same
  counts and repositories.

Data are unchanged. Saved outputs are unchanged except those that quoted the third-party code of D3's first two rounds
and X1, which are redacted as described in the next section (other third-party text in them is described in
`THIRD-PARTY.md`).
